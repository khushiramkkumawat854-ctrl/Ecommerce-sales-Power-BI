E-commerce Sales Dashboard (Power BI)

Project Overview

This project is a professional Power BI dashboard built for an e-commerce business. The dashboard helps management analyze sales, profit, customer behavior, product performance, and return trends using interactive visuals and DAX measures.

Tools Used

- Power BI
- Power Query
- DAX
- Excel / CSV

Dashboard Pages

1. Executive Overview
2. Sales Analysis
3. Product Analysis
4. Customer Analysis
5. Returns & Shipping Analysis

Key KPIs

- Total Revenue
- Total Profit
- Total Orders
- Total Customers
- Profit Margin %
- Return Rate %

Features

- Interactive slicers
- KPI cards
- Monthly sales trend
- Category and state analysis
- Top products
- Customer segmentation
- Return analysis
- Drill-through pages

Business Insights

- Electronics generated the highest revenue.
- Sales peaked during November and December.ss
- Top states contributed the majority of total sales.
- Fashion had the highest return rate.
- Repeat customers generated a significant share of revenue.
